# 🧩 2D Arrays

This folder contains solutions to a variety of matrix-based problems implemented in C++. The problems focus on improving matrix traversal techniques, index manipulation, and logical thinking required for coding interviews.

## 📚 Topics Covered

- Matrix Input & Output
- Row-wise Sum
- Column-wise Sum
- Search in Matrix
- Largest Row Sum
- Wave Print
- Spiral Matrix
- Transpose Matrix
- Rotate Image
- Binary Search in Matrix
- Search in Row & Column Wise Sorted Matrix

## 🚀 Skills Practiced

- Matrix Traversal
- Nested Loops
- Index Manipulation
- Simulation Problems
- In-place Matrix Operations

## 🛠 Language

- C++

## 📌 Objective

The objective of this section is to build confidence in solving matrix-based problems efficiently while understanding different traversal patterns and optimization techniques.
