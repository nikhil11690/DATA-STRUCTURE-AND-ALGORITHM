# 🔍 Binary Search – Problem Solving Pattern

This folder contains problems based on the **Binary Search technique**, one of the most powerful and frequently used algorithms in DSA.

Binary Search is not just a searching algorithm — it is a **pattern** used to optimize solutions from linear time to logarithmic time.

---

## 🧠 What is Binary Search?

Binary Search works on **sorted data** by repeatedly dividing the search space into half.

```text
Time Complexity: O(log n)
```

---

## ⚙️ Core Idea

* Find middle element
* Compare with target
* Eliminate half of the search space
* Repeat until answer is found

---
## 🚀 Why Binary Search is Important

* Reduces time complexity from **O(n) → O(log n)**
* Widely asked in coding interviews
* Used in:

  * Searching problems
  * Optimization problems
  * Answer-based binary search
